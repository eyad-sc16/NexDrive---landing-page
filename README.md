**NexDrive** is a modern, high-performance, Ferrari Editorial-inspired landing page and unified platform designed to connect, monitor, and optimize EV charging networks across the Middle East and North Africa (MENA).

---

## ✨ Features

- **Unified Dashboard Showcase:** Connects charging station operators, logistics fleets, and everyday drivers into a single intelligent platform.
- **Advanced Light & Dark Theme Toggle:** Seamlessly switch between light and dark modes with persistent fixed-theme elements (nav, hero, livery band, footer) and smooth icon transitions.
- **Interactive UI Components:**
  - Dynamic interactive solutions slider with touch/keyboard support.
  - Interactive platform tabs (Operator Console vs. Driver Experience).
  - Real-time number counter animations via Intersection Observer.
  - Custom JavaScript mouseover navigation hover effects.
- **Performance Optimized:** Lazy-loaded imagery (`loading="lazy"`, `decoding="async"`), optimized high-priority hero asset loading (`fetchpriority="high"`), and ultra-clean semantic markup.
- **Fully Responsive & Accessible:** Fully adaptive grid layout tailored for all devices (mobile, tablet, desktop) with high contrast ratios and robust accessibility attributes.

---

## 🛠️ Built With

- **HTML5** (Semantic markup & structured metadata)
- **CSS3** (Custom Properties, Flexbox, Grid, Advanced Animations, and Media Queries)
- **JavaScript (ES6+)** (Intersection Observers, Theme Management, Sliders, and Interactive State Handlers)

## 🚀 Getting Started

To run or inspect this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/nexDrive-landing-page.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd nexDrive-landing-page
   ```

3. **Open the project:**
   - Open `index.html` directly in your browser, or
   - Use a live server extension (like *Live Server* in Visual Studio Code) for the best development experience.
